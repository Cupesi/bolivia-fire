# Bolivia Fire

Open data and reproducible evaluation of satellite fire activity in Bolivia.

The project builds a weekly cell-level benchmark from NASA FIRMS VIIRS S-NPP detections: for every
0.05° cell in Bolivia, the probability of at least one detection in the next seven days. See
[docs/protocol.md](docs/protocol.md) for the evaluation protocol and
[docs/acquisition.md](docs/acquisition.md) for data acquisition.

Status: under active development.
