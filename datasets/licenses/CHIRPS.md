Specify final daily `rnl`, the ERA5 temporal disaggregation, and the extraction
dates. These aggregates map native pixels to project cell centers and summarize
antecedent rainfall; they are not unchanged provider rasters.

Derived window arrays and cell-week summaries may be redistributed with source,
licence link and processing attribution. The licence applies to the data, rather
than converting project code to the data licence.
